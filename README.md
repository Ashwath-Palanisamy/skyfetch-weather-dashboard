# skyfetch-weather-dashboard

A weather dashboard built with HTML, CSS, and JavaScript using the OpenWeatherMap API.

## Features

- Search weather by city name
- Quick city shortcuts (London, Paris, New York, Tokyo)
- Temperature unit toggle (Celsius/Fahrenheit)
- Detailed weather display:
	- City and weather icon
	- Current temperature and description
	- Feels like, humidity, and wind speed
	- Sunrise and sunset times
- API requests handled with Axios and Promises (`.then()`, `.catch()`, `.finally()`)
- User-friendly loading and error states

## Concepts Applied

- JavaScript APIs
- Axios HTTP client
- JavaScript Promises
- DOM manipulation

## Run

1. Open `index.html` in your browser.
2. Enter a city and click Search.
3. Switch between `°C` and `°F` using the unit toggle.
